SQL Procurement Data Analysis
 基于 SQLite 的采购数据分析实践（模拟数据）

1. 项目简介

本项目基于 SQLite 和 SQL 构建采购业务数据分析与核查流程，通过关联供应商、零部件、采购订单、收货、发票及付款等数据，模拟企业采购业务中的数据分析与财务核查场景。

项目重点关注供应商采购金额及集中度、零部件采购价格变化、订单与收货差异、采购订单与发票勾稽，以及发票与付款匹配情况。
项目定位为个人学习与实践项目，所有数据均为虚构模拟数据，不涉及任何真实企业或商业交易。

2. 项目目标

- 分析供应商采购金额及采购集中度，了解供应商采购结构。
- 追踪同类零部件采购价格变化，识别价格波动。
- 核对采购订单与实际收货数量，识别数量差异。
- 关联采购订单与发票，检查采购金额勾稽关系。
- 分析发票与付款记录，识别未结清应付款项。

3. 数据结构

项目使用 SQLite 数据库，包含以下六张核心数据表：

| 数据表 | 业务内容 |
|---|---|
| suppliers | 供应商基础信息 |
| parts | 零部件基础信息 |
| purchase_orders | 采购订单信息 |
| receipts | 采购收货记录 |
| invoices | 采购发票记录 |
| payments | 供应商付款记录 |

通过供应商编号、零部件编号、采购订单编号等关联字段建立数据关系。

 4. SQL 分析场景

01. 供应商采购金额及集中度分析

- 使用 JOIN 关联供应商与采购订单。
- 使用 GROUP BY、SUM 汇总供应商采购金额。
- 分析供应商采购金额及集中度。

 02. 零部件采购价格变化分析

- 按零部件及采购时间整理历史采购价格。
- 使用 LAG 窗口函数比较前后采购价格。
- 识别同类零部件采购价格变化。

03. 采购订单与收货差异分析

- 关联采购订单与实际收货记录。
- 比较订单数量与累计收货数量。
- 识别订单与收货数量不一致的情况。

04. 采购订单与发票勾稽分析

- 关联采购订单与发票记录。
- 比较订单金额与发票金额。
- 识别采购订单与发票金额差异。

05. 发票与付款及未结清应付款分析

- 关联供应商发票与付款记录。
- 比较发票金额与累计付款金额。
- 识别未结清发票余额及相关付款提示。

5. 项目技术

- 数据库：SQLite
- 数据查询：SQL
- SQL 技术：SELECT、WHERE、JOIN、GROUP BY、聚合函数、CASE WHEN、窗口函数（LAG）
- 辅助工具： Python（sqlite3、csv 标准库）
- 数据输出：CSV

6. 项目运行

环境要求

- Python 3
- SQLite（通过 Python 内置 sqlite3 模块调用）
- 无需安装额外第三方 Python 库

运行步骤

1. 下载或克隆本项目。
2. 解压项目文件，进入包含 `run_queries.py` 的项目根目录。
3. 在终端执行：

```bash
python run_queries.py
```

4. 程序自动连接 SQLite 数据库，依次执行 `sql` 目录下的 SQL 脚本，并将查询结果导出至 `outputs` 目录。
