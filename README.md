# SQL 采购数据分析实践（模拟数据）

## 项目目标
使用 SQLite 和 SQL 关联供应商、采购订单、收货、发票及付款数据，练习供应商采购金额、采购集中度、同类零部件采购价格变化和采购交易勾稽分析。

## 数据说明
所有供应商、零部件、订单、金额均为虚构模拟数据，不对应任何真实企业或交易。

## 数据表
suppliers（供应商）、parts（零部件）、purchase_orders（采购订单）、receipts（收货）、invoices（发票）、payments（付款）。

## 运行
在本目录执行 `python run_queries.py`。脚本使用 Python 标准库 sqlite3 执行 sql 目录中的查询，将结果输出到 outputs 目录。

## 分析内容
1. 供应商采购金额及采购集中度（JOIN、GROUP BY、窗口函数）。
2. 同类零部件采购单价变化（LAG 窗口函数）。
3. 采购订单与收货数量差异。
4. 采购订单金额与发票金额勾稽。
5. 发票与付款勾稽及未结清应付款提示。

## 样例测试
- 5 家模拟供应商采购金额及集中度分析。
- 10 笔模拟订单的零部件单价变化分析。
- 2 项订单与收货数量差异。
- 1 项采购订单与发票金额差异。
- 3 项未结清应付款提示。

## 使用边界
查询输出仅为数据核查提示，不等于确认供应商违约、采购价格不合理或会计错报。实际业务需结合合同、订单变更、收货验收、发票、付款审批及质量记录人工复核。
